# Portfolio, CV and personal brand: positioning brief

*Updated 2026-11-11: title changed from "Software Engineer" to **Software Developer** (German: Softwareentwickler), used the same way on the website, CV and LinkedIn.*

Pay particular attention to how my use of AI coding assistants and autonomous coding agents is presented across my CV, portfolio website and software projects.

## 1. Overall professional positioning

I want to be presented as a **Software Developer with expertise in AI-assisted and agentic software development.**

Software development has changed. I use modern AI coding assistants and agents in my workflow to plan, architect, implement, debug, test and deliver applications.

My professional identity should not be limited to someone who writes code by hand. Equally, I don't want to be presented as someone who simply prompts AI to generate applications.

The positioning should show that I have real software development knowledge and use AI agents as tools to extend my capabilities, increase productivity and deliver software faster.

## 2. The portfolio website

The website communicates two complementary strengths:

- **My software development foundation:** programming, frontend and backend development, databases, APIs, system architecture and application development.
- **My AI-enabled development capabilities:** working with AI coding agents, agent orchestration, context engineering, task decomposition, and AI-assisted debugging, testing and implementation.

A dedicated section explains my development philosophy and how I combine engineering knowledge with AI-powered tools:

> **Modern Software Engineering: Building with AI. Engineering with Intent.**

It comes after the Projects section, so the proof comes before the philosophy.

## 3. Presenting projects

Don't just show finished apps, screenshots and tech stacks. Show the engineering process. Where applicable, each case study explains:

- The problem the application solves.
- The architecture and technical decisions.
- How AI coding agents were used in the development workflow.
- How the work was broken down and assigned to agents.
- How generated code was reviewed, tested and refined.
- The challenges and how they were solved.
- The final product and what it does.

Goal: show that I can take an idea from concept to working software while directing and supervising AI-assisted development effectively. Short walkthrough videos are planned.

Case-study template: **Problem → Architecture → Building with AI agents → Review and validation → Challenges → Result → Competencies** (see the six competencies below).

Evidence comes from the **build log** (`BUILD_LOG.md`) kept for every project.

### The six competencies to make visible

Every AI-built project should show that **I designed, architected and orchestrated it**, covering the whole software lifecycle, not just code generation.

| # | Competency | What to show |
|---|---|---|
| 1 | **System design and architecture** | How the app is structured *before* the agent implements it: architecture diagrams, module boundaries, design patterns, technology choices and why. |
| 2 | **Data and API engineering** | Database relationships, indexing, API contracts, validation, authentication, data consistency. |
| 3 | **AI agent orchestration** | How I give the agent context, define tasks, set constraints, review its plans and control implementation. |
| 4 | **Code quality and maintainability** | Separation of concerns, clean code, error handling, refactoring, type safety, maintainable project structure. |
| 5 | **Testing and quality assurance** | Unit, integration and API tests, edge cases, independent verification of AI-generated code. |
| 6 | **Production readiness** | Deployment, configuration management, logging, monitoring, security, performance. |

**How to use it:** each case study includes a short "Competencies" block linking each one to concrete evidence (a diagram, a schema, a test file, a build-log entry, a commit). Not every project needs all six, but the portfolio as a whole should cover all six. The build log captures this evidence as we go.

## 4. The CV

The CV keeps its identity as a software development CV, with an **"AI-Augmented Development"** subsection under technical skills:

- Agentic coding workflows.
- AI-assisted software architecture and implementation.
- AI coding agent orchestration.
- Context engineering and task decomposition.
- AI-assisted debugging and automated test generation.
- Code review, refactoring and validation of AI-generated code.

Tools where applicable: Claude Code, ChatGPT, Codex, GitHub Copilot.

Project descriptions emphasise ownership, technical decisions, implementation and delivery, not simply that AI was used.

## 5. Visual and content direction

AI usage must not dominate the website or make it look like an AI-prompting portfolio. The primary identity is software development. AI-assisted development is an additional professional capability and a modern way of delivering software.

The site communicates technical competence, problem-solving, ownership, adaptability and the ability to deliver complete applications.

## 6. Important distinction

Do **not** position me as:

- Someone who relies on AI to write all their code.
- A prompt engineer.
- An AI Engineer just because I use coding agents.
- Someone whose main skill is operating AI tools.

**Do** position me as:

> A Software Developer who combines solid engineering principles with AI-powered development workflows to build, improve and deliver software products.

## 7. Expected outcome

The CV, website, LinkedIn and project write-ups tell **one consistent story**. A recruiter, technical hiring manager or employer should come away knowing that I:

1. Understand software development.
2. Can design and build applications.
3. Know how to use modern AI coding agents effectively.
4. Can supervise, evaluate and validate AI-generated code.
5. Can take software from an idea to a working product.

The objective: present me as a modern, adaptable software developer who understands not just how to write software, but how software is increasingly built and delivered in the age of AI.
